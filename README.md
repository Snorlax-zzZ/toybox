# Toybox · 玩具箱

乱七八糟小玩意儿。放一些自己折腾出来的宠物、动画和小实验，有东西了就往里添。

## 现在有什么

### [呆猫 · 圆团太刀](pets/daimao/)

把《怪物猎人：崛起》的呆猫外观做成 ChatGPT 宠物，包含九种动作和十六个转头方向，提供成品精灵图集和动画预览。

![呆猫左右四足小跑](pets/daimao/previews/quadruped-run.gif)

[查看动作、文件说明与使用方式](pets/daimao/README.md)

## 怎么逛

每个小玩意儿单独放一个目录，使用方式和文件说明写在各自的 README 里。当前只有呆猫，没有需要部署的服务或统一安装步骤。

## 素材说明

形象来源为《怪物猎人：崛起》的呆猫外观。这套宠物动画使用 AI 辅助制作，属于非官方作品。仓库不包含网上收集的原始参考照片、视频或 GIF。

当前仓库没有统一开源许可证，不将第三方角色权利或图片的使用授权包含在代码许可中。各作品的来源和限制见对应目录；公开可见不代表素材已获得商业使用或再授权许可。
